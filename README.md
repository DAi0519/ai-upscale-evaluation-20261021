# 20图高清超分对比

直接查看20张原图与建筑学长、KS、KS直入各20份实际输出。全部80图片按原始字节保存，不截图、不缩图、不转码。

## 使用

GitHub Pages发布源选择 `main` 分支的 `/docs`。进入主页后选择样本，在四路、隐藏原图或任意两路之间切换；鼠标滚轮缩放，拖动平移，或点击100%查看各自原生像素。

- 同视野模式按同一原图坐标同步，各路显示比例不同。
- 原生像素100%为1个文件像素对应1个CSS像素，仅同步中心位置，各路可见视野不同。
- 两张边界样本的KS使用尺寸适配副本，页面明确提示。
- 本次没有独立高清真值，锐度或纹理增多不等于真实恢复。
- 图片只按当前样本的可见路加载。打开、下载均指向相应实际原文件。
